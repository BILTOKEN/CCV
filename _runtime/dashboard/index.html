❓ 常见问题
三种模式有什么区别？
计划：只读分析，不能改文件。 普通：读写需你确认。 无限：AI 自主执行，不用逐个批准。输入框上方可切换。
怎么切换模型？
点右上角⚙️ 设置，顶部「快速切换模型」会显示当前可用的模型列表，点一下即可切换。模型列表从 API 实时获取。
AI 回复出错或停了？
错误消息旁有🔄 重试按钮，点一下重新发送。也可以按 Ctrl+Enter 重新发送。
AI 要访问工作目录外的文件？
普通模式下会弹窗让你确认。无限模式下自动放行。也可以点击页面底部的工作目录路径手动切换。
快捷键
Ctrl+K 新建对话 · Ctrl+Enter 发送 · Enter 发送 · Shift+Enter 换行
斜杠命令
/compact压缩上下文，省 token
/fork [标题]复制当前对话为新分支
/undo回滚最后一轮对话
/help显示此帮助
怎么生成 Word/PPT/Excel？
直接告诉 AI「帮我生成一个 PPT」，它会用内置的 generate_document 工具创建。内容用 Markdown 格式组织。
API Key 安全吗？
安全。API Key 只存在 U 盘里，不联网上传。所有请求直接从浏览器/终端发到 AI 服务商。

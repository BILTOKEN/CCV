# Claude Code 对话记录 — 2026-05-20

## 修复：AI 网页版打不开 + 故障检测功能修复

### 问题 1：AI 网页版按钮点了没反应
服务器一直在跑（端口 3000 正常），但浏览器没弹出来。
**原因**：`launcher.cs` 里按钮只启动了 node 服务器，没打开浏览器。
**改法**：btn1.Click 里加了 `Process.Start("http://localhost:3000")`。

### 问题 2：故障检测窗口只有第一行显示，其余空白
**原因**：label 坐标用了绝对 y（卡片在面板里的位置），第二行起坐标超出卡片高度看不见了。
**改法**：label 坐标改为相对于卡片的 (10, 4) 和 (40, 4)。

### 问题 3：故障检测"清除残留进程"会杀掉 Claude Code 终端
**原因**：`StopDashboardServer()` 无差别杀所有 node.exe。
**改法**：改用 `GetProcessOnPort(3000)` 精准杀 Dashboard 进程。

### 问题 4：故障检测"打开配置"按钮无效
**原因**：只关了诊断窗口，调用方没打开配置页。
**改法**：直接在诊断窗口内弹 ConfigForm。

### 问题 5：Git 环境检测失败
**原因**：用了 `git` 命令，PortableGit 不在系统 PATH。
**改法**：改用完整路径 `PortableGit\cmd\git.exe`。

### 其他小修
- zombie_nodes 阈值从 ≤2 改为 ≤1
- 删除未使用的 statusLabel 字段
- 故障检测关闭后刷新 API 状态

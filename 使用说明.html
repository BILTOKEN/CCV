CCV v4.2（Claude Code Vision）

插上 U 盘 → 双击启动器 → 选模式开用，就这么简单

支持生成 Word / Excel / PPT 文档

1申请一个 API Key — AI 的"通行证"

API Key 是 AI 服务的"通行证"，软件通过它才能调用 AI 帮你写代码、回答问题。AI 服务按量收费（充 10 块钱能用很久），需要先充值再创建 Key。

放心：你的 API Key 只保存在 U 盘文件里，仅在本地运行，不会上传到任何服务器。

推荐用 DeepSeek（便宜、不用梯子、够用）：

① 打开 DeepSeek 官网
浏览器打开 platform.deepseek.com → 点「API 开放平台」
② 充值（最低金额即可）
左侧点「充值」→ 充 10 元就够了
③ 创建 API Key，复制密钥
左侧点「API Keys」→「Create API Key」→ 输入名称 → 确定
复制那一串以 sk- 开头的字符，这就是你的钥匙

2把 Key 填进启动器（10 秒搞定）

两种配置方式，选一个就行：

方式一：EXE 启动器（推荐，同时配置终端 + 网页）
启动器点 「配置 API 密钥」→ 选供应商 → 粘贴 Key → 保存。
支持 5 个供应商：DeepSeek、OpenAI（自动代理）、Claude、Gemini（自动代理）、OpenRouter。
标注「自动代理」的供应商，终端会自动走本地中转服务，无需额外配置。
方式二：网页版 Setup（仅配置网页版）
打开网页版 → 右上角 Setup → 选供应商 → 填 Key → 自动拉取模型列表 → 保存。
网页版支持更多供应商（Ollama、自定义 API 等），不局限于上面 5 个。
配置完成！接下来选个模式开始用。

3选个模式，开始使用

AI 网页版 ← 新手用这个
点一下 → 浏览器自动打开 → 像 ChatGPT 一样聊天就行。
开启输入框上方的「智能体模式」还能让 AI 读写你的文件。
网页版亮点：
  • 多对话独立隔离 — 切换对话时后台继续运行，消息不串线；关闭页面后 AI 回复自动存盘不丢失
  • 智能体超时保护 — API 请求超时从 60s 延长至 180s，复杂任务不再频繁报 Timeout
  • 网页搜索 — 智能体模式可搜索网页、抓取页面内容，获取最新信息
  • 任务完成提示 — AI 处理完长任务会有浏览器通知，不用一直盯着
  • 语音输入 — 支持语音转文字，不想打字时直接说话
  • 生成文档 — AI 可以直接生成 Word (.docx)、Excel (.xlsx)、PPT (.pptx) 文件
  • 全中文界面 — 工具名称、执行状态、错误提示全部中文化
  • 多供应商无缝切换 — 右上角 Setup 随时换供应商，配置即时生效
Claude Code 终端 ← 进阶用户
命令行界面，编程功能更强：能直接操作项目文件、执行命令、管理 Git。
支持 DeepSeek / Claude / OpenRouter 直连，OpenAI / Gemini 自动走本地代理。
VS Code 编辑器 ← 完整编程环境
便携版 VS Code，无需安装。打开即自动在终端运行 Claude Code，侧边栏预装 Claude Code 扩展。
内含预置配置：禁用遥测、禁用自动更新、跳过信任提示、允许自动任务，所有数据存 U 盘。
打开工作目录
打开 workspace 文件夹，你的代码和文件都放这里。

常见问题

Q: 双击 AI启动器.exe 没反应？
需要 .NET Framework（Win10 自带）。还不行就右键 → 以管理员身份运行。
Q: 点了网页版但浏览器没打开？
手动打开浏览器，地址栏输入 http://localhost:3000。先双击启动器，它会把网页版一起启动。
Q: 网页版能打开但 AI 不回复？
点右上角 Setup，检查 API Key 是否配置正确。DeepSeek 不需要梯子，OpenAI/Claude/Gemini 需要。
Q: 怎么让 AI 生成 Word 或 Excel 文档？
AI 网页版开智能体模式 → 告诉它"整理成 Word 文档"或"做成 Excel 表格"就行。AI 会自动调用文档生成工具，支持 .docx、.xlsx、.pptx 三种格式。
Q: 怎么切换 AI 供应商？
两种方式：① 启动器 →「配置 API 密钥」→ 选供应商 → 保存；② 网页版 → 右上角 Setup → 一键切换。
Q: 网页版支持哪些 AI？
所有 OpenAI 兼容接口都支持：DeepSeek、OpenAI、Gemini、Ollama、LM Studio、自定义 API 等。右上角 Setup 可自动拉取模型列表。
Q: 终端版支持哪些 AI？
Anthropic 兼容接口的（DeepSeek、Claude、OpenRouter）直连使用；OpenAI 和 Gemini 通过内置代理自动翻译。EXE 配置界面有标注。
Q: 网页版和终端版能同时开吗？
能。网页版是独立后台服务，不开启动器也能在浏览器单独用（前提是服务已经在运行）。
Q: 网页版能脱离终端独立用吗？
能。网页版有自己的后台服务，直接调 AI 接口，不依赖终端。
Q: EXE 状态栏的「API 代理」是什么？
本地 API 中转服务。配了 OpenAI 或 Gemini 时，它会自动把终端请求翻译成对应格式发给 AI。配 DeepSeek/Claude/OpenRouter 时终端直连，代理空闲。
